# Pokémon Card Images

Store card photos here for Loui's Binder.

## How to upload

1. Use the **Card Photo Manager** app at `card-manager.html`
2. Or go to **github.com/claudeaispam-maker/louis-binder** → `card-images/pokemon/` → Add file → Upload files

## Image URL format

```
https://raw.githubusercontent.com/claudeaispam-maker/louis-binder/main/card-images/pokemon/filename.jpg
```

## Naming tips

- Lowercase with dashes: `charizard-ex-001.jpg`
- Keep under 500KB for fast mobile loading
